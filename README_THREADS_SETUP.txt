BỘ FILE THREADS CALLBACK CHO GITHUB PAGES

Cách dùng:
1. Giải nén file ZIP này.
2. Upload 3 file HTML vào thư mục gốc repo GitHub Pages:
   - threads-callback.html
   - threads-uninstall.html
   - threads-delete.html
3. Bấm Commit changes.
4. Chờ GitHub Pages cập nhật 1-3 phút.
5. Mở thử các URL:
   https://tuantouristvn.github.io/tuan-tourist-tiktok-app/threads-callback.html
   https://tuantouristvn.github.io/tuan-tourist-tiktok-app/threads-uninstall.html
   https://tuantouristvn.github.io/tuan-tourist-tiktok-app/threads-delete.html
6. Copy các URL này sang Meta Threads API settings.
